# Company logos

SVG assets downloaded from [Simple Icons](https://github.com/simple-icons/simple-icons) on
2026-10-30. Original SVG files are preserved. Source URLs and content hashes are recorded in
`sources.json`; the collection license is retained in `LICENSE.md`.

These are brand marks used in the landing marquee. Their inclusion is a visual selection, not
verification of question coverage, partnership, or endorsement. Company trademarks belong to their
respective owners.

The UI renders the SVGs as monochrome CSS masks so both themes use the same local assets.
